Security Overview

Last updated: 2026-03-18

Nolan Net Worth Tracker uses layered technical and administrative controls intended to protect linked-account data, application secrets, and administrative access.

Identity and access management

  • Administrative access is restricted to authorized accounts and protected with multi-factor authentication.
  • Role-based access control is used to limit privileges to the minimum needed. In the current deployment, administrative access is limited to the owner-admin role.
  • Access to code hosting, automation, and provider dashboards is managed through centralized account-management controls offered by the relevant platforms.
  • Access is reviewed periodically, and credentials or privileges are removed or modified promptly when no longer needed.
  • Non-human authentication relies on provider-managed credentials, OAuth tokens, API keys, and secret storage controls.

Application and network security

  • Data is transmitted between clients, providers, and hosted components using TLS 1.2 or better.
  • Data is stored on systems that apply encryption at rest and restricted administrative access.
  • Secrets are stored separately from source code and are not committed to the public-facing website.
  • The application applies zero-trust principles by requiring authenticated, least-privilege access for administrative operations.

Monitoring and vulnerability management

  • Security issues are monitored through provider tooling, dependency alerts, and vulnerability-scanning controls available to the application environment.
  • Identified vulnerabilities are patched within defined internal timelines based on severity and operational impact.
  • Software components are reviewed for end-of-life status and updated or replaced when necessary.
