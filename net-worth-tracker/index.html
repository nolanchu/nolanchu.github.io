Nolan Net Worth Tracker

Nolan Net Worth Tracker is a private personal finance application used to connect financial accounts in read-only mode, retrieve balances and basic account information, store daily historical snapshots, and display total net worth and account allocation over time.

Private single-user application Read-only financial data access No payments or transfers

What the application does

The application aggregates balance and account-value data from linked financial institutions to track personal net worth over time. It is designed for historical reporting such as current net worth, recent change, and allocation by account category.

How Plaid data is used

Plaid data is used to obtain account balances, account metadata, and related financial information needed for net worth tracking. The application does not use Plaid data for payments, lending, marketing, or resale.

Intended users

The current deployment is intended for the application owner only. It is not marketed as a public consumer product. Even so, security, privacy, and data-handling controls are documented for connected-account workflows.
